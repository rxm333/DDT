# Polices

Toutes les polices de ce dossier sont distribuées sous **SIL Open Font License 1.1** (redistribution autorisée).
Elles sont réduites aux caractères latins (dont les accents français, l’euro et la ponctuation typographique).

| Fichier | Famille | Graisse |
|---|---|---|
| `marcellus-400.woff2` | Marcellus | 400 |
| `cantarell-400.woff2` | Cantarell | 400 |
| `cantarell-700.woff2` | Cantarell | 700 |
| `eb-garamond-var.woff2` | EB Garamond (variable) | 400–800 |
| `eb-garamond-italic-var.woff2` | EB Garamond Italic (variable) | 400–800 |
| `lexend-mega-var.woff2` | Lexend Mega (variable) | 100–900 |
| `pinyon-script-400.woff2` | Pinyon Script | 400 |

Les `@font-face` sont déclarés dans l’embed `global-styles_custom` du composant Global / Styles de Webflow,
pour que les polices s’affichent aussi dans le Designer.
