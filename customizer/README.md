# Personnaliseur Dame de Tours

Le code du personnaliseur (interface client, sauvegarde, devis, commande Shopify, back-office) vit dans le dépôt **privé** [`rxm333/DDT-customizer`](https://github.com/rxm333/DDT-customizer).

Il est privé parce qu'il contient la logique du back-office et des commandes. Ce dépôt-ci est public : jsDelivr en a besoin pour servir `site-scripts`.

Hébergement prévu : application Node.js sur Hostinger, déployée automatiquement depuis la branche choisie sur GitHub.
